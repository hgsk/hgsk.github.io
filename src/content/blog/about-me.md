## 自己紹介

初めまして。**hagi**（[@hagi5593](https://github.com/hgsk)）と名乗らせていただきます。  
わざわざこのような辺境のページへお越しいただき、恐悦至極に存じます。  
私は札幌という北の地で、ソフトウェアエンジニアなどという地道な稼業を営んでおります。

## 好きなもの

私のささやかな趣味についてお話しするお時間をいただけますでしょうか。  
私は **Ruby** という言語をこの上なく愛しておりまして、日常の細々としたスクリプトや、ちょっとした雑務を処理するツールの作成に好んで用いております。世間ではもっと華々しい言語が持て囃されているようですが、カレンダーの管理や TODO リスト程度であれば、自分で Ruby を使って構築した方がよほど快適でございます。わざわざ他人が作った不器用なシステムに自分の生活を合わせる必要など、ございませんでしょう？

また、昨今流行りの **AIツールを活用した開発** とやらにも、人並みに関心を持って取り組んでおります。  
具体的には [agy（Antigravity AI CLI）](https://github.com/antigravity-ai/agy)なるものを使い、煩雑な手作業を機械に押し付けるという、ささやかな抵抗を試みている次第です。人間がやらなくても良い仕事は、賢い機械にやらせるに限りますね。

## このブログについて

ここは、私の技術的な学びや、取るに足らない実験の結果を一方的に書き散らす場所でございます。  
現在は、**Docker / Linux / C# を使った P2P 通信**に関する、いささか難解なハンズオン記事を連載中でございます。もしご興味があれば、どうぞご覧になってください。

- Dockerを活用した、何の特徴もないLinux環境構築に始まり、
- 知っておいて損はない程度のLinux基礎コマンド、ファイルシステム、ネットワークの調査手法、
- HTTP / WebSocket / gRPC / TCP といった、今更説明するまでもない通信プロトコルの比較、
- C# + ASP.NET Core を用いた、いたって平凡なサーバー実装、
- そして最終的には、リアルタイムP2P対戦ゲームの制作という、いささか大層なゴールまでをご案内いたします。

→ もし、途中で挫折せずに付いて来られる自信がおありでしたら、まとめは [ハンズオン目次](/posts/handson-00-index/) からどうぞ。
